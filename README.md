# 💍 Wedding Management System

A web-based application designed to simplify and organize wedding planning. This system helps users manage events, guests, vendors, and schedules in one place.

---

## 🚀 Features

- 👰 Bride & Groom event dashboard
- 📅 Event scheduling and timeline management
- 🧾 Guest list management
- 🎉 RSVP tracking
- 🏨 Vendor management (catering, decoration, etc.)
- 💬 Notifications & updates

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript (or React if applicable)
- Backend: Node.js / Django / Flask (update as needed)
- Database: MySQL / MongoDB (update as needed)
